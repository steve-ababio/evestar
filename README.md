# Polished by Evestair Ghana

Professional cleaning and mobile vehicle care in Accra.

## Development

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Production Build

```sh
npm run build
npm run start
```

## Built With

- Next.js (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- Lucide React & Radix UI
